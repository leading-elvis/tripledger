## 第一批功能驗收（版本 4）

- 支出更正與作廢歷史、旅程更名／封存／解除封存、搜尋及分類／日期／紀錄狀態篩選；封存後唯讀，仍可備份。
- 保存失敗及版本衝突時保留開啟表單的輸入；最新內容須明確核對後才能重送。另一分頁封存旅程時，草稿仍綁定原旅程，不會切到背景列表的其他旅程。
- 收據選檔／拍照入口、預覽、移除及超限壓縮。JPG／PNG／WebP 超過 1 MiB 時嘗試縮小；本機瀏覽器以 5,763,023-byte 合成圖片驗證壓縮至約 987 KB，並確認移除後能重選同檔。尚未做實機拍照與照片文字清晰度驗收。
- 表單、支出列表、旅程設定及共用 UI 已拆分。草稿只保留在目前開啟的頁面，不承諾重整後保留或離線同步。
- 11 項自動化測試涵蓋三人十筆支出、部分還款、更正／作廢、篩選、衝突、重送、歷史／收據備份與獨立還原；另驗證已還款後更正造成反向債務、封存容量保留解除封存空間、歷史鏈與檔案大小限制。舊 schema 1 備份維持原分攤，schema 2 缺少／竄改歷史會拒絕匯入。
- 本機 UI 已操作更正、搜尋、旅程更名／封存／解除封存、草稿衝突；搜尋無結果時帳本總額仍正確。390px 模擬視窗的可用寬度與文件寬度均為 375px，沒有橫向溢位。這不等於 iPhone／Android 實機驗收。
